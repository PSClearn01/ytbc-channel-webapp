# Project Documentation

Welcome to the documentation for the `ytbc-channel-webapp` project. This repository contains a web application built using **SvelteKit 2** + **Svelte 5**, powered by **Vite** and integrated with **Drizzle ORM** and **PostgreSQL**.

## Quick Reference Commands

Here is a summary of the most common commands:

| Action | Command |
| :--- | :--- |
| **Start Dev Server** | `npm run dev` |
| **Run Linter** | `npm run lint` |
| **Run Formatter** | `npm run format` |
| **Generate DB Schema Migrations** | `npm run db:generate` |
| **Push Schema to Database** | `npm run db:push` |
| **Build for Production** | `npm run build` |
